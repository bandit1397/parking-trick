주차 신고 현장 가이드

지구대 경찰관이 주차 관련 신고 현장에서 휴대폰으로 열어 장소 → 상황 → 적용법조·처리기관을 바로 찾는 웹앱입니다. 개 신고 현장 가이드(Handling-Dog-Related-Reports)와 같은 구조, 같은 편집 방식을 쓰고, 주차 신고의 특성에 맞춰 장소 구분과 처리기관을 더했습니다.

설계 단계 시안 (2026.10.12.) · 실제 앱은 README 참고

01무엇이 바뀌었나: 개정 주차장법

주차장법 개정(법률 제21413호, 2026.2.27. 공포)이 2026.8.28.부터 시행 중입니다. 국가법령정보센터 현행 원문과 대조했습니다. 핵심은 도로교통법이 미치지 않던 부설주차장·노외주차장의 출입구 막음에 처음으로 과태료와 견인 근거가 생긴 것입니다.

상황2026.8.27.까지2026.8.28.부터
아파트·상가·오피스텔 부설주차장 출입구를 막고 연락 안 됨도로가 아니어서 강제수단 없음. 차주 연락 협조만 가능과태료 1차 100 · 2차 300 · 3차 이상 500만원 (제6조의3③, 제30조①1호, 시행령 별표6)
관리자 이동 권고 → 불응 시 구청에 조치 요청 → 구청이 이동(견인) (제19조의3⑤, 제15조③~⑤)
민영 노외주차장(유료주차장 등) 출입구 막음강제수단 없음위와 같음 (제15조③~⑤)
구청이 설치한 공영 노외주차장 출입구 막음구획 외 주차 등으로만 이동출입구 막음 자체로 구청이 바로 이동 조치 가능 (제15조②5호 → 제8조의2②)
무료 공영주차장 장기 주차제한적 이동 근거1개월 이상(분해·파손 차 15일) 계속 주차 시 과태료 30 · 50 · 100만원 (제6조의3②, 시행령 제3조)
주차장이 아닌 그냥 사유지(공터·마당·건물 앞)에 무단주차행정 제재 없음바뀐 것 없음. 여전히 차주 연락 협조, 민사 안내, 고의 봉쇄면 형사(일반교통방해·업무방해) 검토

마지막 줄이 중요합니다. 새 법은 “주차장의 출입구”만 다룹니다. 주차장이 아닌 사유지 무단주차는 여전히 법적 처리 수단이 없으므로, 앱에서 이 둘을 첫 화면부터 갈라 보여 주도록 설계했습니다.

02현장 판단 순서

개 신고 앱은 “상황”부터 고르지만, 주차 신고는 장소가 어디냐에 따라 적용 법률과 처리기관이 완전히 달라집니다. 그래서 홈 화면에 장소 선택을 먼저 두고, 사례마다 처리기관을 표시합니다.

1장소

도로인가?도로교통법 제2조1호. 공도이거나, 현실적으로 불특정 다수가 통행하는 공개된 곳
주차장인가?주차장법 제2조1호. 노외주차장(공영·민영), 부설주차장(아파트·상가·오피스텔)
그 밖의 사유지공터, 마당, 건물 앞, 사유 통행로

2행위

금지장소 주정차소화전·교차로·횡단보도·어린이보호구역 등 (도로만)
출입구 막음다른 차가 진출입하지 못하게 함 (주차장만, 신법)
전용구역·장기방치소방차·장애인·충전구역 / 1개월·2개월 방치
고의 봉쇄·보복통행로·영업장 봉쇄, 차를 막거나 훼손

3처리기관

경찰도로 이동명령·견인(도로교통법 제35조), 형사 사건, 차주 연락
구청주차장법 과태료·견인, 장애인·충전구역, 방치차 강제처리
소방서 / 민사소방차 전용구역 과태료 / 순수 사유지 무단점유
경찰구청소방서민사

## 적용법조
- 주차장법 제6조의3 제3항 | 과태료 500만원 이하
  (1차 100 · 2차 300 · 3차 500만원) | 구청 부과

## 현장 확인
- 부설주차장인지 (관리사무소 확인)
- 실제로 진출입을 못 했는지 (사진·영상)

## 처리방향
1. 경찰이 차주에게 연락 시도
2. 관리자가 이동 권고
3. 불응 → 구청 조치 요청 → 이동(견인)

## 사진
  • 판정은 개 앱과 같은 6가지: 형사 위반 검토 적용곤란 적법 참고
  • 장소(새 항목): 홈 화면 장소 버튼으로 사례를 걸러 보는 데 씁니다.
  • 처리기관(새 항목): 사례 머리에 표시. 주차는 경찰이 직접 처리하지 못하고 구청·소방서로 넘기는 경우가 많아 현장에서 가장 먼저 알아야 할 정보입니다.
  • 조문 자동 링크: 법령 이름이 없으면 주차장법으로 봅니다(개 앱은 동물보호법). build.py의 기본 법령 이름 한 줄만 바꾸면 됩니다.

06적용 전에 확인할 것

원문만으로 결론이 나지 않는 부분입니다. 해당 사례는 원문대조: 일부 확인 중으로 두고, 확인되면 고칩니다.

Q1
“출입구”의 범위법률·시행령·시행규칙 어디에도 정의가 없습니다. 출입구 바로 앞 도로, 경사로 중간, 단지 정문과 주차장 입구 사이 통로가 포함되는지 국토부·구청 해석 필요.
Q2
단독주택·빌라 차고도 “부설주차장”인가건축물에 부대해 설치된 주차장이면 문언상 포함될 여지가 있습니다. 관리자가 따로 없는 빌라에서 누가 “권고”하고 구청에 요청하는지도 불분명.
Q3
권고의 방식과 기다리는 시간법은 “권고할 수 있다”만 정하고 방식·기한이 없습니다. 양천구의 실제 접수 창구(주차관리과? 당직실?)와 야간 견인 가능 여부 확인 필요.
Q4
판례 번호 원문 대조재물손괴(차를 막아 못 나가게 함) 대법원 2021.5.7. 선고 2019도13764 판결 등 사례에 인용할 판례를 종합법률정보에서 원문 확인.
Q5
도로교통법 과태료·범칙금 금액소화전·어린이보호구역 등 금액은 시행령 별표와 대조해 기입(시안에는 금액을 넣지 않았습니다).
