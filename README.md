# 주차 신고 현장 가이드

지구대 경찰관이 주차 관련 신고 현장에서 휴대폰으로 열어 **장소 → 상황 → 적용법조·처리기관**을 바로 찾는 웹앱입니다. [개 신고 현장 가이드](https://github.com/bandit1397/Handling-Dog-Related-Reports)와 같은 구조로 만들었습니다.

- 앱 주소: https://bandit1397.github.io/parking-trick/
- 휴대폰에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다. 한 번 열어 두면 전파가 약한 곳에서도 볼 수 있습니다.
- 법령은 국가법령정보센터 현행 원문과 대조했습니다(**개정 주차장법 2026.8.28. 시행**, 도로교통법 2026.7.1. 시행본 등). 현장 참고용이며 최종 판단은 법령 원문과 판례 등을 따릅니다.
- 설계안: [`docs/설계안.html`](docs/설계안.html)

## 무엇이 새로 처리 가능해졌나

개정 주차장법(법률 제21413호, 2026.2.27. 공포, **2026.8.28. 시행**)으로 도로교통법이 미치지 않던 **노외주차장·부설주차장(아파트·상가·오피스텔)의 출입구 막음**에 과태료와 견인 근거가 생겼습니다.

| 상황 | 처리 |
|---|---|
| 주차장 출입구를 막아 다른 차가 드나들지 못함 | 과태료 1차 100 · 2차 300 · 3차 이상 500만원 (구청) · 관리자 권고 → 구청 요청 → 구청 이동 |
| 구청이 설치한 공영주차장 출입구 막음 | 구청이 바로 이동 |
| 무료 공영주차장 1개월 이상 계속 주차 | 과태료 30 · 50 · 100만원 |
| 주차장이 아닌 사유지 무단주차 | **바뀐 것 없음** · 차주 연락, 민사 안내, 고의 봉쇄면 형사 검토 |

## 내용 고치는 방법

GitHub 웹사이트에서 바로 고칩니다. 저장(Commit changes)하면 1~2분 뒤 앱에 반영됩니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 사례 내용 고치기 | `cases` 폴더 → 상황 폴더 → 사례 파일 열기 → 연필 아이콘 → 고치기 → **Commit changes** |
| 사례 추가 | 상황 폴더에서 **Add file → Create new file** → [`cases/_양식.md`](cases/_양식.md) 내용을 복사해서 채우기 |
| 사례 삭제 | 사례 파일 열기 → 오른쪽 위 `…` → **Delete file** |
| 그림 첨부 | `images` 폴더에서 **Add file → Upload files** → 사례 파일의 `## 사진` 아래에 `- images/파일이름.jpg \| 설명` 추가 |
| 홈 화면 "현장 핵심" | [`home.md`](home.md) 고치기 |
| 상황 설명(목록 위 안내) | 상황 폴더의 `_상황.md` 고치기 (관계기관 연락처는 `cases/07-기타/_상황.md`) |
| 법령 조문 | [`laws`](laws) 폴더의 파일 고치기 |
| 되돌리기 | 파일 열기 → **History** → 이전 내용 확인 후 다시 고치기 |

## 사례 파일 쓰는 법

```
---
제목: 아파트 지하주차장 입구를 막고 연락 두절
판정: 위반
장소: 주차장
처리기관: 구청
원문대조: 완료
검색어: 길막, 입구 막음, 연락 안 됨
---

## 적용법조
- 주차장법 제6조의3 제3항, 제30조 제1항 제1호 | 과태료 500만원 이하 (1차 100 · 2차 300 · 3차 이상 500만원) | 구청 부과

## 현장 확인
- 부설주차장의 출입구인지
- 다른 차가 실제로 진출입하지 못했는지

## 처리방향
차주 연락 → 관리자 권고 → 구청 조치 요청 → 구청 이동

## 참고
(필요할 때만)

## 사진
- images/diagrams/tow-procedure.svg | 출입구 막음 처리 절차
```

- **판정**은 `형사` · `위반` · `검토` · `적용곤란` · `적법` · `참고` 중 하나
- **장소**는 `도로` · `주차장` · `사유지` · `공통` 중 하나. 홈 화면 장소 버튼으로 거를 때 씁니다(`공통`은 어느 장소를 골라도 보임)
- **처리기관**은 `경찰` · `구청` · `소방서` · `민사` 중에서 쓰고, 여러 곳이면 `구청·경찰`처럼 `·`로 잇습니다
- **원문대조**는 법령 원문과 맞춰 봤으면 `완료`, 해석이 남았으면 `일부 확인 중`
- **적용법조**는 한 줄에 `법조문 | 처벌 | 비고` 순서, 세로줄(`|`)로 나눔
- 파일 이름 앞 숫자(`01-`, `02-`)가 목록 순서입니다
- 본문에 `제6조의3 제3항`, `도로교통법 제35조`, `시행령 제3조`처럼 조문을 쓰면 앱에서 자동으로 링크가 됩니다. 법령 이름이 없으면 **주차장법**으로 봅니다(다른 법이면 `형법 제366조`처럼 이름을 붙여 쓰세요). 이름 없이 쓴 `시행령`은 바로 앞에 쓴 법령의 시행령으로 봅니다

저장한 뒤 형식이 틀리면 배포가 멈추고, **Actions** 탭에 무엇을 고쳐야 하는지 나옵니다(예: "장소 '아파트' 은(는) 쓸 수 없습니다"). 고쳐서 다시 저장하면 됩니다. 그동안 앱은 이전 내용으로 계속 동작합니다.

## 확인이 더 필요한 부분

`원문대조: 일부 확인 중` 으로 표시한 사례입니다.

- **"출입구"의 범위**: 법령에 정의가 없습니다. 출입구 일부만 막은 경우, 경사로·단지 통로 포함 여부
- **단독주택·빌라 차고**가 부설주차장에 해당하는지, 관리인이 없는 건물에서 누가 권고·요청하는지
- **권고 방식·기다리는 시간**: 법령에 정해져 있지 않음. 양천구청 주차관리과(02-2620-3745)의 실제 접수 방식과 야간 견인 가능 여부

## 폴더 구성

```
cases/      상황별 폴더와 사례 파일 (.md)
laws/       조문 원문 (.md) — 주차장법·시행령, 도로교통법, 형법, 경범죄 처벌법, 소방기본법,
            장애인등편의법, 친환경자동차법, 자동차관리법, 민법
images/     도해 (diagrams)
home.md     홈 화면 "현장 핵심"
site/       앱 화면 코드
tools/      build.py — 위 파일들을 모아 앱을 만듦
docs/       설계안
```

컴퓨터에서 미리 보려면: `python tools/build.py` 실행 후 `_site` 폴더에서 `python -m http.server` → http://localhost:8000
